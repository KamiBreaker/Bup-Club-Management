# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: https://ai.studio/apps/ed5cebc6-89c5-4554-9bce-5fdad7f58926

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   `npm install`
2. Run the app:
   `npm run dev`

The app runs locally without requiring any Gemini API key. The AI assistant endpoint now uses a built-in local fallback so the app is fully runnable offline.
